# naisen-lib

naisen.html（内線・携帯帳）が使う部品を、ページと同じ場所から取れるように置いている。
社内ネットワークで外部の配布サイト（cdnjs・jsdelivr）に届かないとページが止まるため（2026-10-06）。

- `xlsx.full.min.js` … SheetJS 0.18.5（Excel 読み込み）。Apache License 2.0（LICENSE-sheetjs.txt）
- `kuromoji.js`・`dict/` … kuromoji.js 0.1.2（名前のふりがな自動付与）。Apache License 2.0（LICENSE-kuromoji.txt）。辞書は mecab-ipadic（NOTICE-kuromoji.md）
